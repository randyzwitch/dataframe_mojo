# Apple M1 packaged analytical policy evidence

The clean package uses engine commit `576ee8181bbba21f5a9db8170e85d547054c2be2`, CPU build `ff6c898ebce904990460fd81dbdd8210f9e6c5f4629e4db4901f25cc2c9ff515`, and native Metal build `ec16a3a0079af9a05a0ea1314d64a6ef96ad76f4123ec334ea55bd8e959328e6`. Full package, compiler, driver, binary, device, host and execution identities are preserved in the manifest and observations. The Mac mini has an M1, 16 GiB unified memory and eight CPU workers.

The predeclared collection used 192 generated samples, Float32 and Int32, seven warm repetitions and up to 8,388,608 rows. The actual generated training grid contains 284 cases, followed by 128 named mechanism cases held out from this fit. These mechanisms were exposed during prior development; this is not external-suite evidence. Every failed observation remains visible: 117 training and 104 held-out cases succeeded with parity; 167 training and 24 held-out cases failed or were unsupported. Recorded reasons are checked integer nonterminal CPU plans and unsupported floating sum/mean accumulation.

The frozen Float32 record passed the accelerator-safety validation gate (94 distinct training queries, seven validation queries, zero unsafe accelerator decisions). The Int32 record remained unvalidated because its coverage is insufficient (20 training queries and six validation queries). Passing the safety gate does not imply a useful model: all 208 successful held-out cold/warm policy decisions chose CPU. The replay has 46 slower-engine choices, 1.52143 seconds total regret and maximum regret ratio 25.786953. The deliberately conservative Float32 residual bounds miss longer-expression GPU wins. No calibration was installed or enabled.

`regret.json` replays the policy using explicit-engine wall samples plus separately measured preflight overhead. Automatic-execution latency was not directly measured. Failures are retained in `train.jsonl` and `heldout.jsonl`; `manifest.json` lists the complete selected grid. No coefficient or dispatch-bound tuning used the held-out results.
